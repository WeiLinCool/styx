# DESIGN.md — 南风AI

## 气质与意象
"午夜工坊"——极简、克制、高级感。白色画布上，深色线条精准勾勒，光影在最细微处呼吸。苹果级极简主义 + 石头印画的手工温度。关键词：极简白底、苹果质感、留白呼吸、精准克制的光影。

## 视觉策略
- 摄影方向：纯白背景上的极简构图，产品在光线中浮现
- 图形语言：几何极简 + 精准留白，无装饰性渐变
- 交互风格：微妙的位移、呼吸、缩放，克制的动效
- 避免：规则渐变、霓虹光效、过度装饰——一切以内容为王

## 配色方案
| 角色 | 色值 | 意象来源 |
|------|------|----------|
| 背景 | `#FFFFFF` | 纯白画布 |
| 次背景 | `#f5f5f7` | 苹果灰 |
| 卡片背景 | `#f5f5f7` | 朦胧浮现 |
| 主色 | `#1d1d1f` | 墨石 |
| 文字主 | `#1d1d1f` | 石墨黑 |

| CTA按钮 | 白字黑底 | 苹果经典 |

## 字体排版
- 主字体：SF Pro Display / PingFang SC / -apple-system
- 标题：粗体、大号、纯黑、无阴影
- 正文：常规字重、行高1.6、#86868b
- 数字/英文：font-variant-numeric tabular-nums

## 动效与交互
- 页面过渡：淡入（opacity 0→1）
- 按钮：hover微亮，active按压
- 卡片：hover微上浮 + 微阴影
- 滚动：元素渐现（intersection observer）
- CTA按钮：黑底白字，hover微缩放

## 设计禁忌
- 禁止任何彩色渐变（粉紫、蓝紫等）
- 禁止霓虹/发光效果
- 禁止圆角过大（max-radius 16px）
- 禁止装饰性图案和纹理
- 禁止过于复杂的动效
- 禁止深色/黑色背景区域
- 禁止科技蓝
