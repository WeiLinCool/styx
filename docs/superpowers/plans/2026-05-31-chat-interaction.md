# AI Chat Interaction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Improve the AI chat experience with streaming-stable assistant rendering, Markdown display, long-answer collapse controls, and user-side soft deletion of history entries.

**Architecture:** Persist user-side deletion as `agent_runs.deleted_at`, enforce visibility in `AgentRunRepository`, expose deletion through `DELETE /api/agent/runs/[runId]`, and keep the chat UI as derived state. Render assistant content through a focused Markdown component and collapse only completed long answers.

**Tech Stack:** Next.js App Router, React 19, TypeScript, Drizzle/PostgreSQL, native Node test runner, Tailwind CSS, `react-markdown`, `remark-gfm`.
