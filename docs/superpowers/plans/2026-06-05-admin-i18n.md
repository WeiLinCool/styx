# 管理端全面汉化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将管理端所有英文可见文案、状态枚举、表单校验、空态和错误提示统一切换为中文，并通过可维护的文案层集中管理。

**Architecture:** 不改管理端路由结构，只在 `src/features/admin`、`src/app/admin`、`src/app/api/admin` 和少量共享状态映射上做文案收口。先建立一层 admin 专用中文字典/格式化工具，再让页面、表单、状态徽标、空态和 API 错误统一读取它；保留错误码和业务状态码不变，只汉化展示层。

**Tech Stack:** Next.js App Router, React, TypeScript, Zod, existing shadcn/Radix UI primitives.

```ts
  return value
    .replace(/\benabled\b/g, '已启用')
    .replace(/\bdisabled\b/g, '已停用')
    .replace(/\barchived\b/g, '已归档');
}
```
